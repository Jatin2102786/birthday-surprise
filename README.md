# 🎈 Birthday Vault - Secret Time-Locked Birthday Surprise Link

A magical, interactive **Birthday Countdown & Secret Link Vault** website built using standalone HTML5, CSS3, and Vanilla JavaScript.

The website displays a live countdown and keeps the **Birthday Surprise Link locked** until **August 16 at 12:00 AM (Midnight)**.

---

## ✨ Features

- **🔒 Time-Locked Birthday Link**: The primary call-to-action button remains locked with a custom status until **16 August at 12:00 AM**.
- **🎆 Automatic Unlocking Celebration**: On August 16 at 12:00 AM, the vault opens, firing fireworks & confetti 🎊, playing celebration sound chimes, and revealing the clickable **3D Birthday Surprise Link**!
- **🧪 Built-in Test / Preview Mode**: Click the **"Test Mode"** button in the header (or settings gear) to instantly test the unlocked state and preview the secret link!
- **🕯️ Interactive Birthday Cake**: Click the candle flames to blow them out, complete with Web Audio API sound effects and celebration bursts!
- **🎨 Customize Anything**: Easily customize the Recipient Name, Destination Surprise URL, Custom Message, and Target Date right from the built-in Settings Modal (saves to `localStorage`).
- **🌌 Canvas Background**: Starfield particle background with floating transparent birthday balloons.

## 🚀 How to Host & Publish on GitHub Pages (Live in 2 Minutes)

Publishing this website on GitHub is 100% free and takes less than 2 minutes:

### Step 1: Create a GitHub Repository
1. Go to [GitHub.com](https://github.com) and log in.
2. Click the **"+"** icon in the top right and select **New repository**.
3. Name your repository (e.g. `birthday-surprise` or `hbd-august16`).
4. Keep it **Public**, check **Add a README file**, and click **Create repository**.

### Step 2: Upload Project Files
1. In your new GitHub repository, click **Add file** -> **Upload files**.
2. Select and upload the following files:
   - `index.html`
   - `styles.css`
   - `script.js`
3. Click **Commit changes**.

### Step 3: Enable GitHub Pages
1. In your repository, click on **Settings** (top navigation tab).
2. On the left sidebar, click **Pages**.
3. Under **Build and deployment** -> **Branch**:
   - Select `main` (or `master`)
   - Select `/ (root)` folder
4. Click **Save**.

🎉 **Your site is now live!** GitHub will generate a link like:
`https://<your-username>.github.io/<repository-name>/`

Send this live link to your loved one! When they open it, it will count down to August 16 at 12:00 AM and unlock the surprise link right on schedule!

## ⚙️ Customizing the Link & Settings

You can customize the secret link anytime directly on the live website:
1. Open the website.
2. Click the **Gear icon (⚙️)** in the top-right corner.
3. Enter your **Destination Link** (e.g., a YouTube birthday video, Canva presentation, Google Drive album, or custom message).
4. Click **Save Changes**.
